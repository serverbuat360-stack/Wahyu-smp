
# WAHYU SMP

Server Minecraft Survival menggunakan Paper.

## Fitur
- Survival Multiplayer
- Maksimal 20 pemain
- Whitelist aktif
- PvP aktif
- Nether aktif

## Cara menjalankan
1. Siapkan hosting Minecraft yang mendukung Java.
2. Pasang Paper sesuai versi Minecraft.
3. Unggah server.properties.
4. Setujui EULA Minecraft setelah membacanya.
5. Jalankan server dan tambahkan pemain ke whitelist.
